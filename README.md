# Part Patch Utils

Part Patch Utils is a Kerbal Space Program modding utility which uses Module Manager to compute some useful quantities and properties of parts and store them on the part in fields prefixed with `ppu`.

## Dependencies

- [ModuleManager (4.2.3)](https://github.com/sarbian/ModuleManager)
